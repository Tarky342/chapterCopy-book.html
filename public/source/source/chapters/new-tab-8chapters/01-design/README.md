# 第1章：作りたいページを設計する

## 完成イメージ

```text
新しいタブ (New Tab)
├── タブ1「検索」
│   └── キーワード入力欄 + Google検索ボタン
└── タブ2「ニュース」
    └── ジャンル / 再取得 / 見出し・画像・出典・リンク
```

### 役割の分担

- **HTML**：タブボタン、タブ内コンテンツ、Google検索フォームの骨格。
- **CSS**：色を変数で管理し、タブ・カード・スマートフォン・ダークモードの見た目を担当。
- **JavaScript（ブラウザ）**：タブ切替・ショートカット・ニュース表示・キャッシュ。
- **JavaScript（Node.js）**：GNewsへアクセスするAPI中継。秘密のAPIキーをブラウザへ渡さない。

### 要件

| 機能 | 実装する章 | 確認内容 |
| --- | --- | --- |
| 2つのタブと2つの画面 | 第2章 | 対応IDが一致する |
| 見た目・暗色・狭い画面 | 第3章 | 画面幅を狭めても崩れない |
| クリック、Alt+1 / Alt+2 | 第4章 | 正しい画面へ切り替わる |
| Google検索、Alt+D、/ | 第5章 | キーワードがGoogleへ渡る |
| GNews検索、画像・リンク | 第6章 | APIキーをコードへ書かずニュース表示 |
| キャッシュ、障害対応、開発者ツール | 第7章 | 通信失敗時も扱える |
| フォーカス、矢印キー、拡張 | 第8章 | アクセシブルに完成する |

**注意**：Alt+Dはブラウザのアドレスバー操作と競合することがあります。代替操作として `/` を用意します。
