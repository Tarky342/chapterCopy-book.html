# 第3章：CSSでデザインを整える

`index.html`の `<link rel="stylesheet" href="style.css">` がCSSファイルを読み込みます。

1. `:root` の `--page` や `--surface` を変え、見た目を確認してください。
2. `.filetab` がタブ、`.news-card` がニュースカードです。
3. `prefers-color-scheme: dark` はOSのダークモード設定に対応します。
4. `max-width: 600px` の媒体照会はスマートフォン向けです。

この段階では画面の見た目のみ作り、タブ操作は第4章で追加します。
