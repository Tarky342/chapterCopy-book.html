# 初学者向け画像の受入レビュー（人間が確認）

## 1. 読者との適合

- [ ] 読者の問いが一つに絞られている。図を見せる前に、その問いを平易に言える。
- [ ] 画面・コード・操作のうち、その章で必要な**一段**を扱っている。
- [ ] その章で未導入の専門用語や前提知識がない。ある場合は図中か本文で理解できる。
- [ ] **5秒**で注目する場所を指せる。
- [ ] **30秒**で図の関係を自分の言葉で説明できる。
- [ ] 図を見た後、実画面やコードの該当箇所を自分で探せる。
- [ ] 余計な要素を一つ減らしても伝わるなら減らした。

## 2. 教材と事実の一致

- [ ] その章の実装・画面と一致し、後の章の完成状態を混同していない。
- [ ] 概念図、比喩、実スクリーンショットが明確に区別されている。
- [ ] 図の矢印や位置関係が実際のコード・動作と矛盾しない。
- [ ] キャプションと代替テキストだけでも学習上の関係が伝わる。

## 3. 制作・権利・可読性

- [ ] 縮小表示でも主役がわかる。色だけに意味を依存していない。
- [ ] 指定形式・ファイル名で受領した。スクリーンショットは該当章の実画面から取得した。
- [ ] 個人情報、APIキー、無断転載された素材が含まれていない。
- [ ] ユーザーが承認した場合だけ `approved`、実ファイル受領で `delivered`、人間の内容・権利確認後に `verified` にする。

## 判定

「もっと詳しく描く」ではなく、**読者が理解できる最小限まで削れているか**を優先して差し戻す。必要なら最初の一枚を試作し、ユーザーや初学者の反応を得てから次の依頼に進む。
