# V-04-001｜クリックで表示するパネルが切り替わる対応図

## 読者の疑問と到達点

- 読者の疑問: 「ニュースタブをクリックすると、どうして表示する画面が切り替わるの？」
- つまずき: 画面の変化とJavaScriptの記述が別々に見え、クリックがどの表示変更につながるか追えない。
- 図を見た後: クリックされたタブに対応するパネルだけが表示され、もう一方が非表示になる流れを説明できる。

## 制作の目的

本文のコードを読む前に、読者が見慣れた操作前後の画面から入り、クリック、対応するパネル、表示・非表示の変化を一つの因果としてつなげる。初学者が「JavaScriptが画面を作り直す」のではなく、既にある二つのパネルの表示状態を切り替える処理だと理解できるようにする。

## 本文への設置指示

- 対象章・本文: `chapters/new-tab-8chapters/04-tabs/jsでタブを動かす.md`
- 基準位置: `## 読み解く` の直後。`querySelectorAll` と `activateTab` のコード抜粋を読む前に置く。
- 前後で何を学ぶか: 図でクリック前後の画面と対応先を確認してから、本文で `aria-controls`、`activateTab`、`hidden` の記述を照合する。
- 納品先: `chapters/new-tab-8chapters/04-tabs/assets/V-04-001.svg`

## 図の粒度・省略する情報

- 粒度: `one-step`
- 焦点となる要素: クリック前のタブとパネル、クリックされたニュースタブ、クリック後に表示されるニュースパネル、表示状態の変化を示す矢印
- 図中ラベル: `クリック前`、`ニュースをクリック`、`クリック後`、`表示 / 非表示`
- 新出の専門語: `hidden`
- 今回あえて省くもの: `tabIndex`、キーボードショートカット、イベント伝播、DOM全体、ニュース取得。最初の一枚ではクリックと表示状態の因果だけに集中させるため。

## 制作依頼文（そのまま渡せる形）

第4章の本文幅に置ける、白または透明背景の横長SVGを1枚作成してください。左にクリック前のNew Tab画面を小さく描き、検索パネルが表示、ニュースパネルが非表示の状態にします。中央に「ニュースをクリック」という一つの操作と右向き矢印を置き、右にクリック後の同じ画面を描きます。右側ではニュースパネルが表示され、検索パネルが非表示になっていることを、文字と枠線でも示してください。画面全体を詳しく再現するのではなく、検索タブ、ニュースタブ、検索パネル、ニュースパネルだけを主役にします。下に `hidden` は「そのパネルを表示するかどうかを表す」と短く添え、コードが画面の既存部品の表示状態を更新していることが伝わる構図にしてください。

## 必須の要素・ラベル

- クリック前とクリック後の二つの状態。
- `1 検索` と `2 ニュース` のタブ、および `panel-search` と `panel-news` に対応する二つの領域。
- 中央の「ニュースをクリック」と、左から右へ進む一本の矢印。
- クリック後にニュースパネルが表示され、検索パネルが非表示になること。
- `aria-controls="panel-news"` と `id="panel-news"` の対応を、コード片または短い対応線で一度だけ示す。

## 描かないこと・誤解防止

- JavaScriptが新しいHTML要素やニュース記事を作るように見える表現は避け、既存パネルの表示状態だけが変わる図にする。
- `tabIndex`、Altキー操作、API通信、検索結果、ニュース記事、開発者ツールは描かない。
- `aria-controls` が表示を直接切り替えるように見せず、タブとパネルの対応先を示す属性として扱う。
- 実在のブラウザ画面のスクリーンショットとは呼ばず、本文の実装に基づく簡略図であることを図の隅に記す。

## 制作仕様

- 種類: `diagram`
- 形式: `svg`
- 表示サイズ・縦横比: 本文幅640px相当、横16:9を推奨。縮小しても4つのラベルと状態の違いが読める大きさにする。
- スタイル: 実装の画面構成を簡略化した平面図。色だけに頼らず、表示・非表示の文字、枠線、線種で状態を区別する。外部ロゴや素材は使わない。

## キャプション・代替テキスト

- キャプション: ニュースタブをクリックすると、対応するニュースパネルが表示され、検索パネルが非表示になる。
- 代替テキスト: クリック前は検索パネルが表示されニュースパネルが非表示で、ニュースタブをクリックするとニュースパネルが表示され検索パネルが非表示になる流れを示す図。

## 根拠・検証方法

- `chapters/new-tab-8chapters/04-tabs/index.html` の `aria-controls="panel-news"` と `id="panel-news"` を、タブとパネルの対応の根拠にする。
- `chapters/new-tab-8chapters/04-tabs/tabs.js` の `panels[i].hidden = !selected;` を、選択したパネルの表示状態が変わる根拠にする。
- `chapters/new-tab-8chapters/04-tabs/tabs.js` の `tab.addEventListener('click', () => activateTab(index));` を、クリックが処理のきっかけになる根拠にする。
- 完成後、`04-tabs/index.html` を実行して検索タブとニュースタブを交互にクリックし、画面の表示状態と開発者ツールの `hidden` 属性が図と一致するか確認する。実装にない状態や値は追加しない。

## 見た後の小さな行動

`04-tabs/tabs.js` の `panels[i].hidden = !selected;` を探し、`selected` が `true` になるパネルがどれかを画面のクリック結果と照合する。
