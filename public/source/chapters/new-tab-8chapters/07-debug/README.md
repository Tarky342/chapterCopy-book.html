# 第7章：エラーを見つけて修正する

第6章のファイルを土台として、`app.js`に5分キャッシュ・破損キャッシュの除去・通信失敗時の旧記事表示を加えています。

## 自動テスト

`node --test test.mjs` をこのフォルダーで実行してください。
テストではタブとパネルの数、JavaScript構文、鍵ファイルが公開されないこと、キー未設定時のエラーを確認します。
（GNewsへの実通信はキーとネットワークが必要なので、自動テストには含めません。）

## 開発者ツールで確認（F12）

1. **Elements**：ボタンが2個、`tabpanel`も2個。`aria-controls`と`id`が一致。
2. **Console**：`SyntaxError` が発生していないか。テンプレート文字列はバッククォートで囲む。
3. **Network**：`/api/news`のHTTPステータスが200か。401/403/429等はAPIキー・利用枠を確認。
4. **Application → Local Storage**：`new-tab-gnews-v1`を変更・削除し、キャッシュ破損時の復帰を確認。
5. **Offline**：保存済みキャッシュがある場合、ネット接続が切れても以前の記事を表示することを確認。

実行方法は第6章と同じ：`.env.example`→`.env`、`node --env-file=.env server.mjs`。
